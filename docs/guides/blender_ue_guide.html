1sozlash

Sahna birliklari: 1 birlik = 1 sm Blender

UE santimetrda ishlaydi. Blender da oldindan shunga moslab olsak, eksportda masshtab muammosi bo'lmaydi: personaj 180 birlik baland bo'ladi.

  1. O'ng paneldagi Properties›Scene (konus va shar belgisi) ni oching.
  2. Units bo'limida: Unit System = Metric, Unit Scale = 0.01, Length = Centimeters.
  3. N bilan yon panelni ochib, View›Clip End ni 100000 qiling, aks holda katta model kesilib ko'rinadi.
  4. File›Save As: D:\My_apps\Ertugrul\art\blender\personaj.blend. Repo ichida saqlansa git ga tushadi.
2model

Past poligonli personaj: qutidan boshlab Blender

O'yindagi "temir odam" 11 bo'g'imli. Blender da ham shu proporsiyani saqlang: tos 89 sm balandlikda, bosh 17 sm radiusda, umumiy bo'y 180 sm. Shunda kodimizdagi pozalar va kamera balandligi mos keladi.

  1. Shift+A Mesh›Cube. N panelda Item›Dimensions: X 26, Y 32, Z 46 (ko'krak).
  2. Tab bilan Edit Mode. 3 yuz tanlash. Pastki yuzni tanlab E bilan pastga cho'zing (tos), keyin oyoqlar uchun ikki marta E.
  3. Ctrl+R halqa kesik: tizza va tirsak joyiga bittadan kesik qo'ying, aks holda bukilmaydi.
  4. Simmetriya: Properties›Modifiers (kalit belgisi) Add Modifier›Generate›Mirror, o'q X. Faqat o'ng yarmini modellang.
  5. Yumshoq shakl kerak bo'lsa Add Modifier›Subdivision Surface, Levels Viewport 1. Eksportda modifikatorlar qo'llanadi.
  6. Nomlang: Outliner da ob'ektni ikki marta bosib SK_Ertugrul. UE da shu nom bilan ko'rinadi.

3rang

UV va rang: bizning materialga mos Blender

Loyihada barcha ob'ektlar bitta protsedural PBR materialdan foydalanadi: rang vertex rangidan, naqsh esa alfa kanalidan tanlanadi (mato 0.10, charm 0.32, metall 0.50, jun 0.70, badan 0.90). Blender da ham vertex rang bilan bo'yasangiz, tekstura umuman kerak bo'lmaydi.

  1. Yuqorida Texture Paint yorlig'iga o'ting. Chap panelda Tool›Mode = Vertex (Blender 4.x da bu Vertex Paint rejimi, Ctrl+Tab menyusidan ham tanlanadi).
  2. Properties›Data (yashil uchburchak) Color Attributes›+: nomi Col, Domain Vertex, Data Type Color (Byte Color emas, shunda alfa saqlanadi).
  3. Rang tanlab (Tool›Color) yuzlarni bo'yang. Alfa qiymatini rang oynasidagi A slayderida qo'ying: kaftan uchun 0.10, kamar 0.32, zirh 0.50, yuz 0.90.
  4. UV kerak bo'lsa (Fab teksturali material uchun): UV Editing yorlig'i, Edit rejimida A, keyin U Smart UV Project, Island Margin 0.02.
Alfa kanali muhim: bizning materialda alfa 1.0 "oddiy" naqsh, 0.0 esa "tuproq". Bo'yashda alfani unutib 1.0 da qoldirsangiz, personaj yaltiroq tekis ko'rinadi.
4skelet

Rigify bilan skelet va uch animatsiya Blender

  1. Edit›Preferences›Add-ons, qidiruvga Rigify, katakchani belgilang.
  2. Object rejimida Shift+A Armature›Human (Meta-Rig). Tab bilan suyaklarni tanangizga moslang (G bilan bo'g'imlarni tizza, tirsak, yelka joyiga).
  3. Properties›Data (armatura belgisi) Rigify Buttons›Generate Rig. Yangi rig ob'ekti paydo bo'ladi.
  4. Avval meshni, keyin Shift bilan rig ni tanlang, Ctrl+P With Automatic Weights.
  5. Animatsiya: Animation yorlig'i, rig ni tanlab Ctrl+Tab Pose Mode. Timeline pastida Dope Sheet›Action Editor, New: A_Idle. Suyakni buring, I Location & Rotation. 1, 15, 30 kadrlarda kalit qo'ying.
  6. Shu tarzda A_Walk (24 kadr, oyoqlar navbatma-navbat) va A_Attack (18 kadr, o'ng qo'l orqadan oldinga). Har bir action uchun Action Editor da qalqon belgisini (Fake User) bosing, aks holda saqlanmaydi.
Eng oddiy yo'l: o'yin hozircha o'z kodli pozalarida ishlaydi. Faqat mesh eksport qilsangiz ham (skeletsiz), 6-qadamdagi statik ob'ekt yo'li orqali darhol ko'rinadi. Skeletli personaj kodga ulanishi 7-qadamda.
5eksport

FBX eksport: UE uchun aniq katakchalar Blender

  1. Object rejimida mesh va rig ni tanlang (statik ob'ekt bo'lsa faqat mesh). Ctrl+A All Transforms.
  2. File›Export›FBX (.fbx). O'ng paneldagi katakchalarni sxemadagidek qo'ying.
  3. Fayl nomi: SK_Ertugrul.fbx (skeletli) yoki SM_Uy.fbx (statik). Papka: D:\My_apps\Ertugrul\art\fbx\.
6import

UE ga import va bizning kodga ulash Unreal

  1. Muharrirda Content Drawer (Ctrl+Space). Content/ErtAssets papkasini yarating: o'ng tugma New Folder. Kodimiz aynan shu papkani skanerlaydi.
  2. FBX faylni papkaga sudrab tashlang. Ochilgan oynada: statik ob'ekt uchun Skeletal Mesh o'chiq, Generate Missing Collision yoqiq, Vertex Color Import Option = Replace; personaj uchun Skeletal Mesh yoqiq, Import Animations yoqiq, Skeleton = None (yangi yaratiladi). Import All.
  3. Statik ob'ekt: nomi SM_Rock_*, SM_Tree_*, SM_Pine_* bo'lsa dunyo quruvchisi uni o'zi topib qoya yoki daraxt sifatida qo'yadi. Boshqa nom bo'lsa manifestga yozing.

Skeletli personaj hozircha kodga ulanmagan: o'yin protsedural "temir odam"dan foydalanadi. Ulash uchun keyingi ish: UErtHeroBody o'rniga USkeletalMeshComponent va animatsiya blueprint'siz C++ AnimInstance. FBX tayyor bo'lganida "davom et" deb yozing, shu qadamni kod bilan qilaman.
