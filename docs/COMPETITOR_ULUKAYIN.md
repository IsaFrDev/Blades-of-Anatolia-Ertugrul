## Ularning kamchiliklari (sharhlardan) — bizda qanday
- Jang: parry vaqti nomuvofiq, yengil zarbani spam qilib yutish mumkin, urilgach qochib bo'lmaydi → bizda parry oynasi 0.25 s, stamina, kombo oynasi, dodge i-frame, ijro (execute), qalqon sindirish.
- Nazorat nuqtalari yomon, o'tkazib bo'lmaydigan kat-sahnalar → bizda checkpoint har bosqich, Esc bilan o'tkazish.
- Bo'sh dunyo, izlanish mukofoti yo'q → bizda 48 epizod + yon kvestlar, o'lja, kashfiyot xaritasi (fog of war), GPS.
- FPS tushishi (qal'a, ob-havo) → bizda 3 render preseti (Ultra / PS5 / Series S).
- UI kursor xatosi, tarjima xatolari → bizda dinamik HUD, 3 til.
- Faqat 1–2 bob (~5 soat) → bizda 48 epizod (1227–1261).

## Keyingi qadamlar (ulardan o'rganib)
1. Ot parvarishi: boqish (go'sht/olma), tarash — ot sog'ligi va tezligi bonusi.
2. Hunarmandchilik: teri/temir → o'q, zirh; temirchi NPC.
3. Tushda jumboq matnlari (dialog) va "tushdagi qaror" real dunyoga bayroq beradi.
4. Yuz ifodasi: skeletli personajga morph/anim (Fab Paragon assetlari bilan).
5. Qo'shimcha xarita: g'or/er osti (Karacahisar ostida).
