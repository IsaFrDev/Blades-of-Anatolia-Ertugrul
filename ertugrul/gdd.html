Epizod arxetiplari

Asosiy harakat turi

Sizning talabingiz: "hammasi ham ot bilan bog'liq bo'lib qolmasin." Ot endi 7 epizodda asosiy — 15%. CI testi 12 dan oshmasligini tekshiradi.

O'yinning yuragi

Mix

Siz aytdingiz: mix qo'lga hamma epizodda tushsin. Mana buning tizimi — 48 epizodda 48 xil ko'rinish, bitta mexanika. Ko'pchilik o'yinda jarohat HP bar; bu yerda jarohat — o'yinchi o'zi bilan olib yuradigan tarix.

Faza I — Soya

EP001 – EP023

Mix hali qoqilmagan, lekin har epizodda ko'rinadi: obyekt, boshqa odamning kaftidagi chandiq, tushda, so'zda. O'yinchi buni sezmaydi — keyin qayta o'ynaganda dahshatga tushadi.

Faza II — Og'riq

EP025 – EP036

Jarohat — cheklov. Parry oynasi 180ms → 110ms. Og'ir qurol yo'q. Kamonda 3 o'q, keyin qon. Devorga chiqishda arqonni tishlab ushlash.

Faza III — Belgi

EP037 – EP048

Jarohat — kuch. Odamlar uni taniydi. Ba'zi joylarda afzallik beradi: hech kim sizni jangchi deb hisoblamaydi, shuning uchun siz eng yaxshi josussiz.

EP024 — nima uchun bu QTE emas

Bog'langan holatda boshqaruv o'yinchida qoladi — u kamerani buradi va xonani 40 soniya davomida o'zi o'rganadi. Keyin ekranda: «Tortib oling — [E] tez bosing». O'yinchi qanchalik tez bossa ham qo'l chiqmaydi. 20 soniyadan keyin tugma ko'rsatuvi o'chadi va yangi yozuv paydo bo'ladi:

// EP024 — o'yinchi jismonan taslim bo'lishni TANLAYDI.
// Bu — kinematik hech qachon bera olmaydigan narsa.

if (ElapsedSec > 20.f && !bReleasePromptShown)
    ShowReleasePrompt();          // "QO'YIB YUBORING."

// Taymer yo'q. O'yin KUTADI. Tugma qo'yib yuborilgandan keyin:
void UErtWoundComponent::TriggerNailEvent(float NewCeiling)
{
    HandIntegrity = 0.f;
    MaxIntegrity  = NewCeiling;   // 55 — hech qachon qaytmaydi
    Phase         = EErtHandPhase::Fresh;
    Sabr          = FMath::Min(Sabr, 20.f);

    TraumaSubsystem->OnNailDriven(GetOwner());
    // → chap qo'l animset · "Qilich yo'li"ning 6 mahorati o'chadi
    // → "Sol Yol" daraxti 6 bepul ochilish bilan ochiladi
    // → IMC_Combat → IMC_Combat_Left · Post_EP024 data layer

    SaveSys->WriteIrreversibleCheckpoint(TEXT("EP024_NailDriven"));
    // Darhol saqlanadi — "qayta yuklab" bekor qilib bo'lmaydi.
}

Tarixiy asos

Bu mo'g'ul usuli emas — va o'yin buni ochiq aytadi. Ṣalb (mixlab qatl) Christian Lange tadqiqotiga ko'ra "saljuqiy xronikalarda eng ko'p tilga olinadigan qatl usuli". Tasmīr hujjatlashtirilgan: 1248-yil Damashq hodisasida qurbonning qo'llari, yelkalari va oyoqlari mixlangan.

Mixni saljuqiy jallodi qoqadi. Noyan uni keyinroq o'rganadi va takrorlaydi — va bu uni kuchliroq qiladi.

Accessibility

Qiynoq sahnalarini yumshatish yoki butunlay o'tkazib yuborish · tez bosish → 3 soniya ushlab turish · qon darajasi · ekran silkinishi 0 · epizod boshida kontent ogohlantirishi. Natija saqlanadi, sahna o'tkazib yuboriladi.

Bir qo'lli boshqaruv rejimi alohida ma'no kasb etadi: EP024 dan keyin Ertug'rul ham bir qo'lda o'ynaydi.

Core gameplay

Jang og'ir va jazolovchi: uch kishi sizni o'ldirishi mumkin, beshtasi — albatta. Referens uchburchagi: Ghost of Tsushima (oqim) × Kingdom Come (og'irlik) × Sekiro (poza).

Muvaffaqiyatli parry ham qo'lni og'ritadi. Bu — tizimning yuragi: o'yinchi parry-spam qila olmaydi, har parry qaror bo'ladi.

Iymon — endi mexanika

Sizning JSON'ingizda "Iymon shkalasi" so'z edi. Endi u ishlaydi: asirni ozod qilish +8, va'dani buzish −10, kechirish +15, qasoskorlik −25.

0–25: alplar buyruqni sekin bajaradi, flashback ×1.5 · 51–75: Sabr regen +50% · 76+: «Sukunat» — jang oldidan 3 soniya sekinlashuv, va EP048 da eng yaxshi final.

Fraksiyalar — neytral qololmaysiz

6 fraksiya (Saljuqiy · Ayyubiy · Templar · Mo'g'ul · Axiy · Vizantiya), har biri −100…+100. Birida obro' oshsa, dushmanida tushadi — dushmanlik matritsasi bo'yicha.

Templar–Mo'g'ul dushmanligi atigi −0.2: tarixan ular ittifoq izlagan. EP031 shu ustiga qurilgan.

Texnik

Arxitektura

To'qqiz UE5 moduli, bir tomonlama bog'liqliklar, data-driven epizodlar. Java tomonda faqat meta-servislar — o'yin to'liq offline ishlaydi.

ErtugrulCore          poydevor: tag, interfeys, save, world state
  ├── ErtugrulGameplay  GAS, jang, harakat, ErtWoundComponent
  ├── ErtugrulHistory   Kodeks, Bilge Göz, Safar Daftari
  └── ErtugrulOnline    Java backend, telemetriya, live-ops
        │
        └── ErtugrulNarrative  UErtEpisodeDataAsset · quest grafi
              │                UErtIntroDirector  · dialog
              ├── ErtugrulWorld  streaming, ob-havo, oba, olomon
              │     └── ErtugrulAI  nerge, Mass Framework, adaptive boss
              └── ErtugrulUI     faqat o'qiydi, hech narsa o'zgartirmaydi

ErtugrulEditor        epizod validatori — CI da build'ni to'xtatadi

Dizayner xato qila olmaydi

IsDataValid() build vaqtida tekshiradi: ID formati, indeks izchilligi (sizning "season": 0 bug'ingiz), har epizodda mix beat, yil 1227–1261 oralig'ida, BAHSLI uchun scholar_note, dangling kodeks/prerequisite, 8+ dushman ogohlantirishi, arxetip takrorlanishi, kontent ogohlantirishi.

Java: 101 fayl, ~14 900 qator

Spring Boot 3.3 · Java 21 · Postgres + Flyway · Redis · Kafka · MinIO. Cloud save (vector clock konflikt yechimi), kodeks sinxroni, Safar Daftari PDF eksporti, telemetriya, live-ops balans (patchsiz), tanlov statistikasi.

Anti-cheat hech kimni jazolamaydi — modifikatsiyalangan save faqat global statistikadan chiqariladi.

Eng katta texnik risk: ikkita to'liq jang animseti (o'ng va chap qo'l). Chap qo'l animatsiyalari mirror qilinmasligi kerak — mirror "noto'g'ri" ko'rinadi va o'yinchi buni sezadi. 6–8 kunlik alohida mocap, ~1.1 GB xotira, ikki barobar QA. Buni prototip bosqichida hal qilish shart.
