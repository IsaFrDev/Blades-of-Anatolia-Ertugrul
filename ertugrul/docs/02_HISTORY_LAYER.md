## 1. ASOSIY MUAMMO VA YECHIM

### Muammo
*Diriliş: Ertuğrul* seriali — go'zal, lekin **~60 yillik tarixni 1 o'n yillikka siqadi**. Bayju Noyan 17 yil erta keladi, Ibn Arabiy chodirda yashaydi, Qayi shajarasi XV asrda ixtiro qilingan.

Agar o'yin buni **fakt** sifatida ko'rsatsa:
- Tarixchilar va sharhlovchilar o'yinni **yiqitadi** (Metacritic, YouTube).
- O'yinchi **yolg'on** o'rganadi — bu sizning maqsadingizga zid.
- Turkiya, Ozarbayjon, Yevropa bozorlarida **turli reaksiyalar** bo'ladi.

Agar o'yin serialdan **butunlay voz kechsa**:
- Sizning eng katta auditoriyangizni yo'qotasiz.
- Dramatik kuch yo'qoladi.

## 4. «SAFAR DAFTARİ» (Journey Log) — o'yinchining shaxsiy tarixi

Har o'yinchining o'z **qo'lyozma daftari** bor. U avtomatik to'ldiriladi, lekin **o'yinchi ovozida** yozilgan:

```
   ┌─── 632-yil, Rabiʿul-avval  /  1234-yil, Dekabr ───┐
   │                                                   │
   │  "Sultan Han'da uch kun qoldik. Karvonboshi       │
   │   Mes'ud aytdiki, bu yerda uch kunlik ovqat       │
   │   va boshpana bepul — musulmonga ham,             │
   │   nasroniyga ham, yahudiyga ham.                  │
   │                                                   │
   │   Men so'radim: nega?                             │
   │   U kuldi: 'Chunki sulton savdodan               │
   │   qo'rqmaydi. Qo'rqqan sulton — qashshoq          │
   │   sulton.'                                        │
   │                                                   │
   │   Turgutning qo'li hali ham og'riyapti."          │
   │                                                   │
   │   🔗 [Sultan Han] [Karvonsaroy tizimi] [Dirham]   │
   └───────────────────────────────────────────────────┘
```

**Nima uchun bu kuchli:**
- O'yinchi **o'z tanlovlarini** qayta o'qiydi → hissiy bog'liqlik
- Tarix **quruq fakt emas, kechinma** bo'ladi
- Daftar **eksport qilinadi** (PDF/rasm) → ijtimoiy tarmoqda ulashiladi → **marketing**
- Backend'da saqlanadi → qurilmalar orasida sinxron

## 5. IKKI TAQVIM (Hijriy + Milodiy)

Butun o'yin **ikki taqvimda** ko'rsatiladi — bu davr uchun tarixiy jihatdan to'g'ri va o'yinchiga yangi bilim beradi.

```
    ╭──────────────────────────────────────╮
    │   624 Ramazon  ·  1227 Avgust        │
    │   AMANOS TOG'LARI                    │
    ╰──────────────────────────────────────╯
```

Har epizod intro'sida (siz so'raganingizdek — **yillar bilan**) shu format ishlatiladi. Sozlamalarda: `Faqat milodiy / Faqat hijriy / Ikkisi ham`.

## 7. «SHUBHA SAHNALARI» (Uncertainty Scenes) — eng ijodiy element ⭐

**Bu — men taklif qilayotgan asosiy yangilik.**

Tarixda manbalar ziddiyatli bo'lgan **7 ta muhim lahzada**, o'yin **to'xtaydi** va ekran qora-oq bo'ladi:

```
    ════════════════════════════════════════════════════
                    ⟡  SHUBHA  ⟡
    ════════════════════════════════════════════════════

      Bu lahza haqida manbalar bir-biriga zid.
      Tarixchilar hozirgacha rozi emas.

      SIZ QAYSI RIVOYATNI O'YNAYSIZ?

      ┌────────────────────────────────────────────┐
      │ ① OTAM — SULAYMON SHOH                     │
      │   Aşıkpaşazade (1480-yillar) va usmonli    │
      │   xronikalari shunday yozadi. Fyrot        │
      │   daryosida cho'kadi.                      │
      │   → Klassik serial yo'li                   │
      ├────────────────────────────────────────────┤
      │ ② OTAM — GUNDUZ ALP                        │
      │   Usmonning tangalarida shunday yozilgan.  │
      │   İnalcık, Ortaylı, Öztuna shu fikrda.     │
      │   → Tarixiy jihatdan kuchliroq yo'l        │
      └────────────────────────────────────────────┘

      Qaysi tanlasangiz ham — Kodeksda IKKALASI ham
      to'liq yoziladi.
    ════════════════════════════════════════════════════
```

**Nima uchun bu ajoyib:**
1. **Tarixiy halollik** — o'yin bilmagan narsani bilaman demaydi
2. **Qayta o'ynash sababi** — ikkinchi o'yinda boshqa versiya
3. **Hech kimni xafa qilmaydi** — an'anaviy va akademik pozitsiya ikkisi ham hurmatlanadi
4. **Bahs tug'diradi** — YouTube, Reddit, TikTok'da bepul marketing
5. **Mexanik ta'sir** — tanlov `world_state`ga yoziladi, S4 finalidagi shajara sahnasini o'zgartiradi
