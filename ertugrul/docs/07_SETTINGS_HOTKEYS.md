## 5.2 ⭐ «Tez bosish → ushlab turish» (accessibility, EP24 uchun kritik)

```cpp
void UErtStruggleComponent::HandleStruggleInput(const FInputActionValue& V)
{
    if (Settings->bMashingAsHold)
    {
        // ♿ Rejim: 3 soniya ushlab turish = 20 soniya bosish
        HoldTime += GetWorld()->GetDeltaSeconds();
        StruggleProgress = FMath::Clamp(HoldTime / 3.0f, 0.f, 1.f);
    }
    else
    {
        // Standart: har bosish +0.04, lekin doim 0.85 da to'xtaydi
        StruggleProgress = FMath::Min(StruggleProgress + 0.04f, 0.85f);
    }

    // ⚠️ Qanday bo'lsa ham 1.0 ga yetmaydi — qo'l chiqmaydi.
    // 20 soniyadan keyin UI o'zgaradi: "QO'YIB YUBORING."
    if (ElapsedSec > 20.f && !bReleasePromptShown)
        ShowReleasePrompt();
}
```
