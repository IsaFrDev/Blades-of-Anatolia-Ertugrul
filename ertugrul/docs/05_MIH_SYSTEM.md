## 0. FALSAFA

Ko'pchilik o'yinlarda jarohat = **HP bar**. U kamayadi, keyin to'ladi, keyin unutiladi.

Bizda jarohat = **o'yinchining o'zi bilan olib yuradigan tarixi**.

| An'anaviy | «Mix» tizimi |
|---|---|
| HP tushdi → dori → tugadi | Qo'l teshildi → **hech qachon tuzalmaydi** |
| Jarohat — jazо | Jarohat — **identifikatsiya** |
| Unutiladi | Har epizodda **eslatiladi** |
| Faqat raqam | Animatsiya, ovoz, dialog, kamera, UI, AI, iqtisod |

**Maqsad:** 48-epizodda o'yinchi o'z qo'liga qarasa — u yerda **o'z tarixi** bo'lsin.

### 5.2 `Sabr` (Sabr) — qarshi tizim

Flashback = jazо emas. Uni **boshqarish** mumkin:

```
   Sabr o'sadi:                      Sabr tushadi:
   + zikr/meditatsiya (EP26+)        − uxlamaslik
   + odamlar bilan gaplashish        − yolg'izlik
   + Safar Daftariga yozish          − flashback'ni e'tiborsiz qoldirish
   + o'g'illarni o'rgatish           − afyun

   Sabr > 70  →  flashback ehtimoli ×0.4
   Sabr < 30  →  flashback ehtimoli ×2.0 + yangi turlar
```

> **Bu — mexanika sifatida ishlangan psixologik chidamlilik.** Va u tarixiy: *sabr* — davrning markaziy tushunchasi.

```cpp
// ErtugrulGame/Private/Wound/ErtWoundComponent.cpp  (asosiy mantiq)
#include "Wound/ErtWoundComponent.h"
#include "Env/ErtWeatherSubsystem.h"
#include "Trauma/ErtTraumaSubsystem.h"

float UErtWoundComponent::GetParryWindowMs() const
{
    // Chiziqli emas — jarohat oshgani sari og'riq TEZROQ o'sadi
    if (Phase == EErtHandPhase::Intact) return 180.f;

    const float T = FMath::Clamp(HandIntegrity / 100.f, 0.f, 1.f);
    // 110ms (0%) → 165ms (100%), egri chiziq bilan
    return FMath::Lerp(110.f, 165.f, FMath::Pow(T, 0.7f));
}

float UErtWoundComponent::GetFlashbackChance(float BaseChance) const
{
    if (Phase == EErtHandPhase::Intact) return 0.f;
    const float SabrMul = (Sabr > 70.f) ? 0.4f : (Sabr < 30.f ? 2.0f : 1.0f);
    return FMath::Clamp(BaseChance * SabrMul, 0.f, 1.f);
}

void UErtWoundComponent::TriggerNailEvent(float NewCeiling)
{
    const float Old = HandIntegrity;
    HandIntegrity = 0.f;
    MaxIntegrity  = NewCeiling;          // 55 — hech qachon qaytmaydi
    Phase         = EErtHandPhase::Fresh;
    Sabr          = FMath::Min(Sabr, 20.f);

    // Butun jang tizimini qayta yozadi: chap qo'l animset, yangi skill tree
    if (UWorld* W = GetWorld())
        if (auto* Trauma = W->GetSubsystem<UErtTraumaSubsystem>())
            Trauma->OnNailDriven(GetOwner());

    BroadcastAndClamp(Old);
    // ⚠️ Save'ga darhol yoziladi — bu qaytarib bo'lmaydigan nuqta
}

void UErtWoundComponent::TickComponent(float DT, ELevelTick, FActorComponentTickFunction*)
{
    if (Phase == EErtHandPhase::Intact) return;

    const float Old = HandIntegrity;
    HandIntegrity += SampleEnvironmentalDrain() * DT;   // sovuq/nam manfiy
    BroadcastAndClamp(Old);
}

void UErtWoundComponent::BroadcastAndClamp(float Old)
{
    HandIntegrity = FMath::Clamp(HandIntegrity, 0.f, MaxIntegrity);
    RecomputePhase();
    if (!FMath::IsNearlyEqual(Old, HandIntegrity))
        OnHandIntegrityChanged.Broadcast(HandIntegrity, Old);
}
```
