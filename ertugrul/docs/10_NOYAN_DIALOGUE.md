## 2.2 Noyan KIM

> **U — buxgalter.**

Bu — obrazning yadrosi. Noyan **qirg'in qilmaydi — hisoblaydi**. Har qishloq — raqam. Har asir — kategoriya (hunarmand → yashaydi, jangchi → o'ladi). Har mag'lubiyat — daftar sahifasi.

**Uning haqiqiy qo'rqinchi:** u odamlarni yomon ko'rmaydi. U **ularga befarq**. Nafrat — munosabat, befarqlik — yo'qlik.

```
   NOYANNING UCHTA HAQIQATI (u ishonadigan, va qisman TO'G'RI narsalar)

   1. «Dunyo bo'linmagan bo'lishi kerak.»
      Yagona qonun (Yasa), yagona yo'l, yagona soliq → savdo, tinchlik,
      xavfsizlik. Mo'g'ul imperiyasida savdogar Xitoydan Vengriyagacha
      xavfsiz yurgan. Bu — HAQIQAT.

   2. «Tez o'lim — rahm-shafqat.»
      Qarshilik ko'rsatgan shahar butunlay qiriladi; taslim bo'lgan shahar
      omon qoladi. Bu — dahshatli, lekin IZCHIL. Va u qamal muddatini
      qisqartirgan (kamroq umumiy o'lim). Bu — Noyanning mantiqi.

   3. «Sizlar bir-biringizni bizdan battar qiynaysiz.»
      ⭐ Va bu — o'yinning eng og'riqli haqiqati. Ertug'rulning qo'lini
      MO'G'UL emas, SALJUQIY mixlagan. Noyan buni biladi va uni
      qurol sifatida ishlatadi.
```

# 3. ⭐ «ШАКАЛ» METAFORASI — to'liq rivojlanish

## 3.1 Nima uchun shakal (çakal)?

Noyan bosib olgan xalqlarni **bo'ri** deb atamaydi (bo'ri — turk-mo'g'ul dunyosida sharafli hayvon). U ularni **shakal** deydi:

| Bo'ri | Shakal |
|---|---|
| Guruh bo'lib ov qiladi | Yolg'iz yuradi |
| O'z o'ljasini o'zi tutadi | **Boshqaning qoldig'ini yeydi** |
| Jimgina | **Ovoz chiqaradi, qichqiradi** |
| Sadoqatli | **Sotadi** |

> **NOYAN:** *"Bo'ri — dushman. Shakalni dushman deb bo'lmaydi. Shakalni sanaysan."*

## 3.2 ⭐ Metafora 5 bosqichda o'sadi (bu — dizaynning kaliti)

```
   EP32  ①  «Shakal» — HAQORAT
          Noyan mag'lublarni shunday ataydi. Ertug'rul jahli chiqadi.

   EP36  ②  «Shakal» — TASNIF

          Uning daftarida ustun bor: «shakallar: 12,909»

   EP44  ③  «Shakal» — AYBLOV
          Noyan Ertug'rulga: "Seni MEN sotmadim. Sening xalqing sotdi.
          Kim shakal — men aytdimmi, yoki ular ko'rsatdimi?"

   EP47  ④  «Shakal» — E'TIROF
          Noyan: "Men ham shakalman. Men ham xonimning qoldig'ini yeyman.
          Farq shuki — men buni bilaman."

   EP48  ⑤  «Shakal» — QAYTARISH  ⭐
```

## 6.2 ⭐ Til to'sig'i mexanikasi (Noyan sahnalarida)

```cpp
// Noyan mo'g'ulcha gapiradi. Subtitr TARJIMONNI kutadi.
// Lekin ba'zan u to'g'ridan-to'g'ri turkiy tilda gapiradi — va subtitr DARHOL chiqadi.
// O'yinchi buni sezadi: "u bizning tilimizni biladi." Bu — qo'rqinchli.
void UErtDialogueRunner::PlayLine(const FErtDialogueLine& L)
{
    const bool bPlayerUnderstands =
        !L.bRequiresInterpreter ||
        WorldState->HasFlag(TAG_Codex_Unlocked_MongolLanguage);   // ⭐ kodeks ochsa tushunadi

    Audio->Play(L.VO);

    if (bPlayerUnderstands)
        Subtitles->Show(L.Text, /*DelaySec=*/0.f);
    else
        // Avval mo'g'ulcha ovoz tugaydi, KEYIN tarjimon gapiradi
        Subtitles->ShowAfterInterpreter(L.Text, InterpreterVO, /*DelaySec=*/1.8f);

    if (!L.LinkedCodexId.IsNone())
        Codex->OfferUnlock(L.LinkedCodexId);
}
```
